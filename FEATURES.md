# ESSU DocuFlow — Features

Online document request portal for the ESSU Graduate School. Students request
documents; staff review and release them.

## Accounts & Sign In

- Student self-registration
- Email verification before first login
- Login with "remember me" (30 days)
- Forgot / reset password
- Staff accounts created by invite only
- Role-based access (students can't reach staff pages)

## Student Portal

- Dashboard of your requests and statuses
- 3-step request form: document → requirements → purpose
- Purpose picked from a set list
- Upload requirements as PDF or photo
- See which requirements are still missing
- Re-upload files while pending or when corrections are asked
- Download your document once approved
- Notifications for every status change
- Edit profile, email, and password

## Staff Portal

- Dashboard with request counts
- Search and filter all requests
- View request details and submitted files
- Approve and upload the finished document
- Reject with a reason
- Request corrections and flag specific requirements
- Manage requestable documents and their requirements
- Upload downloadable templates
- Reports on request activity
- Notifications for new requests
- Edit own profile and password

## Admin (plus all staff features)

- Manage student accounts
- Invite and manage staff
- Admin-only pages locked to regular staff

## Email Notifications

- Account verification
- Password reset
- Staff invitation
- Approved / rejected / corrections needed
- Staff warned if an email fails to send

## Files & Documents

- Uploads kept in cloud storage
- Download links expire after 7 days
- Templates for students to download
- Full status history per request
